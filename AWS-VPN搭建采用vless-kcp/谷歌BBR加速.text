太好了，这正是我们优化的机会！下面我给您提供精确的、可直接复制粘贴的命令，来为您的服务器开启 BBR 加速。

### 开启 BBR 加速三步走

请按照顺序执行以下命令：

**第一步：修改系统配置文件**

我们需要编辑 `/etc/sysctl.conf` 这个文件。因为这是系统文件，所以需要在命令前加上 `sudo` 来获取管理员权限。

```bash
sudo nano /etc/sysctl.conf
```

执行后，会打开一个文本编辑器。请用键盘的向下方向键，移动到文件的**最底部**。

**第二步：在文件末尾添加 BBR 配置**

在文件的最末尾，粘贴下面这两行内容：

```
net.core.default_qdisc=fq
net.ipv4.tcp_congestion_control=bbr
```

粘贴完成后，按下 `Ctrl + X` 组合键，然后按 `Y` 键，最后按 `Enter` 键，即可保存并退出。

**第三步：让配置立即生效并验证**

1.  执行下面的命令，让系统重新加载配置，使刚刚的修改生效：
    ```bash
    sudo sysctl -p
    ```
    您应该会看到刚才添加的那两行配置信息显示出来。

2.  最后，我们再次运行您刚刚用过的检查命令来验证：
    ```bash
    sudo sysctl net.ipv4.tcp_congestion_control
    ```

这一次，您应该会看到输出结果变成了：

```
net.ipv4.tcp_congestion_control = bbr
```

如果看到了这个结果，**就代表您的服务器已经成功开启了 Google BBR 加速！** 您的网络性能将会得到显著提升。
